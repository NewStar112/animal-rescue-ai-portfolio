# Animal Rescue AI

面向资源有限的民间动物救助组织，设计一套可信动物档案与领养协作系统。

> 当前阶段：单人 Alpha 规划  
> 已完成：问题定义、产品范围、数据模型与 AI 架构设计  
> 正在进行：数据底座和多模态可信建档  
> 尚未完成：真实义工验证、专家评测和业务结果验证

## Problem

数百只救助动物的信息长期分散在义工记忆、聊天记录、表格和照片中，
导致查询、更新、交接和领养流程难以追踪。

## Product Direction

- 可信多模态建档
- 人宠匹配
- 领养问答助手
- 受控管理 Agent

## Why AI

AI 用于理解非结构化资料、发现冲突、生成可追溯草稿和理解自然语言操作。

规则系统负责硬约束、权限和状态机，最终决定由人完成。

## Evidence Boundary

当前只处于单人 Alpha 规划和开发阶段。

朋友测试只用于通用可用性，不替代领域专家判断。

现场义工 Beta 和全量建档尚未开始。

## Data Policy

This repository contains synthetic and anonymized materials only.

No production data, personal information, private recordings or credentials are stored in this repository.
